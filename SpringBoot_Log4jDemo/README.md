### Spring Boot 4 Enterprise Logging & Architecture Demo

A cutting-edge Spring Boot REST API demonstration designed to practice modular layered architecture, interfacecontracts, compile-time type safety, and production-ready log configurations using SLF4J and Log4j. 

### 🚀 Key Learning Objectives

* **Java 24 Capabilities**: Utilizing modern Java features while retaining optimized compilation targeting enterprise runtime environments.
* **Spring Boot 4.x Architecture**: Building decoupled web layers on Spring Boot's newest generation, focusing on faster initialization and native runtime efficiency.
* **Logging Facade Pattern**: Combining **SLF4J** (Simple Logging Facade for Java) with **Log4j** to route and bridge layered logs safely without tight coupling.
* **Compiler Safety & Contract Enforcement**: Using @Override on implementations to dynamically match service layer contracts at compile time.
* **Granular HTTP Control**: Implementing ResponseEntity structures inside REST controllers to deliver explicit HTTP statuses (200 OK, 404 Not Found) and customized payloads.

### 🛠️ Tech Stack & Prerequisites

* **Language**: Java 24 (Optimized for cutting-edge virtual thread concurrency)
* **Framework**: Spring Boot 4.x Generation (Built on Spring Framework 7)
* **Logging System**: SLF4J API paired with Log4j implementation/bridging
* **IDE**: IntelliJ IDEA

### 🧠 Core Architecture Breakdown

### 1. Interface-Driven Design & @Override

The app decouples layers using IGreetService. The service implementation (HomeService.java) uses the @Override annotation. This instructs the Java 24 compiler to verify signature constraints immediately, blocking compilation if discrepancies or typos occur. 

### 2. Contextual Application Logging

Instead of relying on heavy, unbuffered console printers, the workflow splits tasks using hierarchical logging: 

* **HomeController**: Tracks incoming REST API traffic thresholds utilizing INFO and DEBUG scopes.
* **HomeService**: Records underlying algorithmic execution routes via the high-density TRACE tier.
* **Log Routing**: SLF4J acts as a uniform wrapper api while Log4j maps underlying storage protocols, duplicating tracking data to both standard console streams and disk files (log/log.txt).

### 3. REST Control via ResponseEntity

Rather than resolving directly to raw objects, handlers pack payloads inside explicit ResponseEntity<T> containers. This allows explicit control over the outgoing transport packet header arrays and context-specific status codes.
